# portal-intro
개인 웹 포털 프로젝트 소개 페이지

## 작품은 웹에서 수정합니다

Pages CMS (`https://app.pagescms.org`)에 GitHub로 로그인한 뒤,
`hoodie5622/portal-intro` 저장소의 `main` 브랜치에서 **포트폴리오 작품 관리**를 엽니다.
이름, 설명, 사용 기술, 사이트/코드 주소, 대표 이미지를 입력하고 저장합니다.
저장된 커밋의 GitHub Pages 배포가 성공한 다음 공개 페이지에 반영됩니다.

- 작품 원본: `portfolio.json`의 `projects` 배열
- 편집 양식: 저장소 루트의 `.pages.yml`
- 이미지 위치: `assets/`
- 더 이상 사용하지 않는 파일: `portfolio-data.js` (전환 시 제거, 기존 Git 이력과 별도 백업에 보관)
- 화면 코드를 바꾸지 않는 한, 작품 편집에 터미널 push는 필요하지 않습니다.
- CMS를 처음 쓰려면 본인 GitHub 로그인과 Pages CMS GitHub App 설치 승인이 필요합니다.
- 예전 `public-site` 사본의 데이터를 새 저장소 위에 복사하지 마세요.
- `main`이 아니라 다른 브랜치에 저장하면 현재 공개 사이트에는 자동 반영되지 않습니다.
- 작품 목록에서 삭제하더라도 사용한 이미지 파일은 자동 삭제하지 않습니다. 다른 작품에서 사용 중인지 확인하세요.
- 공개 사이트에 토큰·비밀번호·개인 일정·백업 파일을 올리지 마세요.

자세한 사용법과 전환 제한은 [CMS 안내](CMS_GUIDE.md)를 참고하세요.
