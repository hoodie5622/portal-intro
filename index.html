02 / FEATURES

하나씩 연결한 기능들

아래는 개인 포털의 기능 설명입니다. 실제 기록이나 체험용 데이터는 표시하지 않습니다.

01

일정 관리

할 일을 추가하고 수정하며, 완료 상태와 오늘 남은 일정을 확인합니다.

02

공부 기록

공부 시간을 측정하고 쉬는 시간을 제외해, 저장한 학습 기록을 모아 봅니다.

03

지식 아카이브

배운 내용과 참고 링크를 메모하고, 검색과 분류로 다시 찾아봅니다.

04

도구 모음

사칙연산, 단위 변환, 날짜 차이 계산처럼 자주 필요한 도구를 사용합니다.

05

데이터 백업

일정·저장된 공부 기록·메모를 JSON 파일로 보관하고 다시 불러옵니다.

06

개인화 설정

표시 이름, 라이트·다크 테마, 처음 열릴 화면을 선택합니다.

03 / BUILD LOG

개발하면서 정리한 것

  1. 화면부터 만들기

    HTML·CSS·JavaScript로 메뉴, 테마, 대시보드를 만들고 필요한 기능을 추가했습니다.

  2. 오류를 고치고 기준점 남기기

    공통 기능과 일정 코드를 분리하고 Git으로 변경을 기록했습니다. 직접 시험한 기본 저장·검색·복원 흐름을 확인했습니다.

  3. 공개할 내용만 분리하기

    개인용 관리 화면과 별도로 소개 페이지를 준비했습니다. 전체 기능이나 모든 오류 상황의 검증이 끝난 것은 아닙니다.

04 / SCOPE

소개와 개인 기록은 구분합니다.

이 페이지에는 개인 일정, 공부 기록, 메모, 백업 파일을 연결하지 않았습니다. 로그인이나 실제 포털 체험 기능도 제공하지 않습니다.
